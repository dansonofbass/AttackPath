Evidence policy: uploaded PDF bytes are never parsed for security findings. Observed means observed in the bundled legacy sample, not the current PDF. Synthetic infrastructure, simulated events, correlated relationships and inferred impacts remain distinct. Legacy CVSS and severity are retained as source fields, including mismatches; historical recommendations are labeled as sample evidence.
